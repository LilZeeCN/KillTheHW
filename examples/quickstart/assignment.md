# 《Linux 系统与网络基础》实验一：环境与常用命令

## 一、实验目的
1. 掌握 Linux 终端常用命令（`uname`, `df`, `ip/ifconfig`, `ps`）。
2. 理解用户权限与基本系统状态排查方法。

## 二、实验内容与步骤
1. **系统信息与磁盘查看**：
   - 查看当前内核版本与系统架构；
   - 查看根分区磁盘挂载与使用率；
   - 截取终端运行结果并记录。
2. **进程与网络测试**：
   - 检查当前正在运行的 Python 进程；
   - 测试本地网络回环与默认网关连通性。

## 三、思考题
1. 为什么在多用户服务器环境中不建议直接使用 `root` 账户日常操作？
2. `df -h` 与 `du -sh` 的统计原理有何区别？如果删除了大文件但 `df` 空间未释放，可能是什么原因？
